# Мой Илизаров — PWA demo

## Что есть
- Две вкладки: «Крутки» и «Перевязки».
- Металлические кольца 1–4 с отверстиями, болтами и гаечным ключом.
- Настраиваемое время подъёма, первой крутки и отбоя.
- Отметки выполнения, сохранение данных в localStorage.
- Календарь октября 2026 года с историей событий: 16 октября госпитализация, 17 октября операция, 18 октября первая перевязка, 20 октября выписка и вторая перевязка, 23 октября первая крутка и третья перевязка.
- Прогноз перевязок на 7, 14 или 30 дней с настраиваемым интервалом.
- Service Worker для офлайн-кеша при размещении на HTTPS.
- Пример запроса разрешения на уведомления.

## Запуск
Для офлайн-кеша и установки PWA нужны HTTPS и manifest/service worker. Самый простой вариант:
1. Распаковать архив.
2. Разместить содержимое на HTTPS-хостинге (например, GitHub Pages или Netlify).
3. Открыть ссылку в Safari на iPhone.
4. В Safari нажать «Поделиться» → «На экран Домой».

Можно открыть `index.html` локально для проверки интерфейса, но Service Worker и установка PWA в таком режиме не работают.

## Ограничения
- Уведомления в этом демо не гарантируются, особенно если вкладка закрыта. Для надёжных уведомлений iOS необходима проверка установленной PWA на конкретном устройстве; в некоторых сценариях потребуется серверный push.
- Данные хранятся в браузере устройства. Очистка данных сайта удалит их.
- Прогноз перевязок является календарной оценкой по выбранному интервалу, а не медицинским назначением. Выбирайте интервал по рекомендациям лечащего врача.
- Расписание круток требует сверки с назначенной схемой коррекции.
