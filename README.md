# Мой Илизаров — версия 2

- Более спокойный и аккуратный интерфейс, без декоративных псевдометаллических колец.
- Дневной прогресс-бар и отметки четырёх круток.
- История выполнения по датам и экспорт резервной копии JSON.
- События можно редактировать или удалять через компактное меню `···`.
- История и настройки сохраняются в IndexedDB браузера (с резервом localStorage для совместимости).
- Календарь событий и прогноз перевязок.

## Обновление GitHub Pages
1. Распакуйте архив.
2. В репозитории `my-ilizarov` выберите Add file → Upload files.
3. Загрузите файлы из папки проекта в корень репозитория и подтвердите Commit changes. Если GitHub спросит про совпадающие имена, подтвердите замену файлов.
4. Откройте сайт и обновите страницу. Если осталась старая версия, закройте PWA полностью и откройте ссылку в Safari, затем обновите страницу.

## Важно про хранение
Данные сохраняются в локальной базе данных браузера на этом устройстве. Это не облачная база: для синхронизации между устройствами нужен отдельный сервер/облачный проект и настройка доступа. Экспортируйте JSON-резервную копию перед очисткой данных сайта или сменой устройства.

Прогресс миллиметров рассчитывается пропорционально числу отметок и введённой вручную цели. Это не измерение фактической длины ноги и не рекомендация по коррекции. Значение цели должно соответствовать назначению лечащего врача. Прогноз перевязок также нужно сверять с врачом.

## Исправления мобильной версии
- Исправлена адаптивная сетка формы на узких экранах Safari; поля не должны пересекаться.
- Поля ввода используют размер шрифта 16 px, чтобы Safari не увеличивал страницу при фокусе.
- История показывает сохранённые дни и позволяет открыть день отдельно.
- Данные каждого дня остаются отдельными; старые отметки не сбрасываются при переходе к сегодняшней дате.
- Обновлён номер кэша service worker, чтобы браузер загрузил новые файлы.


## Исправления v8
- При запуске открывается рабочая область текущего дня; старые записи остаются доступными через историю.
- Исправлен фильтр дат в истории круток.
- Если на текущем дне уже стоят все четыре отметки, появляется явное восстановление: можно перенести их на вчера, если вчерашняя запись отсутствует, либо очистить только сегодняшние отметки, если запись за вчера уже есть. Перед изменением требуется подтверждение.
- Обновлён ключ кэша сервис-воркера, чтобы браузер запросил новую версию файлов.
- Для узких экранов поля формы используют сжимаемые колонки и одноколоночную раскладку.

Перед подтверждением переноса/очистки внимательно проверь дату. Экспортируй JSON-резервную копию, если не уверена, к какому дню относятся отметки.
