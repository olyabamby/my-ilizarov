# Мой Илизаров · версия 10

## Что исправлено
- При открытии приложение автоматически показывает сегодняшний день по локальной дате устройства.
- Однократная осторожная миграция переносит четыре отметки с сегодняшней даты на вчерашнюю, только если вчера пусто и сохранённый активный день указывает на сегодняшний.
- История показывает три последних календарных дня, включая пустой сегодняшний день.
- Прогноз перевязок учитывает события, в названии или заметке которых указана перевязка, даже если событие одновременно отмечено как крутка.
- Обновлена версия service worker cache до v13.

## Установка
Загрузите содержимое архива в корень репозитория GitHub Pages, заменив файлы с теми же именами. Не удаляйте иконки и manifest. Перед заменой сохраните резервную копию данных из приложения.

Дата берётся с часов устройства. Интернет-синхронизация для календарной даты не нужна; проверьте дату, время и часовой пояс iPhone, если они неверны.


В версии 11 исправлены интервалы в показателе миллиметров и отображение полей времени на iPhone. Добавлена адресная одноразовая коррекция истории: при обнаружении записей за 24 и 25 октября по четыре крутки и пустого 23 октября, отметки 25 октября переносятся на 23 октября, 24 октября сохраняется, а 25 октября открывается пустым.


В v13 добавлено редактирование истории круток по дням и отметка перевязки кнопкой в выбранной дате календаря.


В v13 последнее время крутки рассчитывается за час до отбоя. Карточка прогресса упрощена: добавлены явные промежутки между числом и «мм», убран повторяющийся текст, сокращён декоративный элемент.
